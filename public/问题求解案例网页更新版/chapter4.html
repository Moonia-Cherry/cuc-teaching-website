4. 图像处理

图像处理是指利用计算机对图像进行分析和处理，以达到特定需求的技术。它在工业自动化、医疗诊断、安全监控等领域有着广泛的应用。Python中有多个用于图像处理的库，如Pillow（PIL）、OpenCV、SimpleCV等。

Pillow是Python Imaging Library（PIL）的一个分支，支持多种图像文件格式，并提供了强大的图像处理功能。本章将介绍如何使用Pillow库进行图像文件操作、图像编辑、图像合成、图像增强以及添加滤镜、添加文字等常用图像处理方法。

4.1 需求分析

在日常工作和生活中，图像处理技术扮演着越来越重要的角色。无论是制作证件照、创作艺术作品、对老旧照片进行修复，或是批处理图片，都离不开图像处理技术的支持。通过学习和掌握图像处理技术可以创作出独特的图像作品。

  1. 批处理图像文件：来源不同的图像（如社交媒体、相机拍摄、网络下载等），其文件尺寸、分辨率、色彩风格等各不相同，直接使用可能无法满足特定的展示需求（如网页展示、打印、社交媒体发布等）。需高效对图像进行批量处理，自动完成优化操作。
  2. 图像合成与创意设计：制作海报、广告或平面设计时，需用到图像混合、遮罩合成、图像增强、滤镜效果等技术，完成有创意的图像作品。
  3. 满足不同用途的图像处理：不同场景对图像处理要求不同——社交媒体发布需调整尺寸和风格，电商需批量优化商品图，摄影后期需调色加滤镜，印刷出版需调整分辨率和色彩模式。

（1）图像色彩模式

色彩模式是按规则描述颜色的方法，不同模式适用于不同场景。常用色彩模式包括RGB、CMYK、HSV、Lab等，具体说明如下：

  • RGB色彩模式：基于光的三基色（红R、绿G、蓝B），不同比例混合形成各种色光。适用于显示器、投影仪、相机等屏幕显示设备，是工业界颜色标准。

图4-1 RGB色彩模型

  • CMYK色彩模式：基于油墨反射原理，减法三原色（青色C、洋红M、黄色Y）+黑色K（强化暗调）。适用于打印机、印刷系统，浓度范围0%~100%。

图4-2 CMYK色彩模式

  • HSV色彩模式：基于人类视觉感知，包含色相（Hue）、饱和度（Saturation）、明度（Value）。色相是颜色名称，饱和度越高色彩越纯，明度决定明暗。适用于图像编辑。

图4-3 HSV色彩模式

  • Lab色彩模式：国际照明委员会（CIE）制定的设备无关色彩空间，包含人类视觉可感知的所有颜色，弥补RGB和CMYK不足。处理速度快，适用于色彩管理。

图4-4 Lab色彩模式

色彩模式是数字图像中表示颜色和色彩信息的方法。不同的色彩模式适用于不同的应用场景，它们决定了图像中可以使用的颜色数量和类型。图像处理中有时需要将图像从一种色彩模式转换为另一种模式，以满足特定的需求。如图4-5所示，分别以HSB、RGB、Lab和CMYK表示颜色信息。

3. 案例实现

案例分为“图像分割”和“图像拼合”两部分。

（1）图像分割

将一张图像均匀分割成九张小图像。首先需要计算原始图像的宽度和高度，将其分别除以3，得到每个小图像的尺寸。然后检查目标文件夹是否存在，若不存在则自动创建文件夹，以便将所有小图像有序存储。通过双重循环遍历图像的行和列，依次截取每个小图像的区域，并将其保存为独立的文件。为了确保每个小图像的文件名唯一，使用计数器为文件名添加序号。最终，原始图像被分割为九个等大的小图像并保存这些图像，为后续的图像处理或拼合操作提供基础。 

# 1. 导入库
import os
from PIL import Image

# 2. 读取图像并计算裁剪尺寸
im = Image.open('images/校园风光.jpg')
width = im.width // 3  # 每个小图像的宽度（整除3）
height = im.height // 3 # 每个小图像的高度（整除3）

# 3. 初始化参数与创建文件夹
start_x = 0  # 裁剪起始X坐标
start_y = 0  # 裁剪起始Y坐标
z = 1        # 图像命名计数器

# 检查文件夹是否存在，不存在则创建
if not os.path.exists('imgs'):
    os.mkdir('imgs')

# 4. 双重循环裁剪图像（3行3列）
for i in range(3):  # 遍历行
    for j in range(3):  # 遍历列
        # 计算裁剪区域：(左, 上, 右, 下)
        left = start_x
        upper = start_y
        right = start_x + width
        lower = start_y + height

        # 裁剪并保存
        crop = im.crop((left, upper, right, lower))
        crop.save(f"imgs/aa{z}.jpg")

        # 更新X坐标和计数器
        start_x += width
        z += 1
    # 重置X坐标，更新Y坐标（进入下一行）
    start_x = 0
    start_y += height

在每次循环中，使用im.crop()根据当前的坐标和计算出的尺寸,裁剪出一个小图像。使用crop.save()将裁剪好的小图像保存到名为imgs的文件夹中。文件名由变量z和前缀“aa”组成，确保每个图像的名称都是唯一的。每次循环后，将左上角坐标的x轴向右移动裁剪尺寸的宽度，确保每次循环都能裁剪出新的图像区域。每次循环结束后，将计数器z增加1，以便为下一个裁剪的图像命名。程序运行后，imgs文件夹中的内容如图4-9所示。

（2）图像拼合

将九张小图像拼合为一张九宫格图像，首先需要创建一个新的空白图像文件，其尺寸略大于原始图像，以便为图像之间的间隙留出空间。然后，通过双重循环遍历九张小图像，依次将它们粘贴到新图像的指定位置。为了增强视觉效果，可以在图像之间添加一定的间隙（如10像素），使九宫格布局更加清晰。最终，所有小图像被整齐地拼合成一张完整的九宫格图像，并可以通过保存功能将其存储为新的文件，或直接显示以供查看。 

# 1. 新建空白图像（比原图大20像素，背景白）
im_out = Image.new("RGB", (im.width + 20, im.height + 20), "white")

# 2. 初始化粘贴坐标
x = 0
y = 0

# 3. 读取所有小图像并存储到列表
im_list = []
for i in range(9):
    im_list.append(Image.open(f'imgs/aa{i+1}.jpg'))

# 4. 双重循环粘贴图像
p = 0  # 小图像列表索引
for i in range(3):  # 遍历行
    for j in range(3):  # 遍历列
        # 粘贴当前小图像
        im_out.paste(im_list[p], (x, y, x + width, y + height))
        # 更新X坐标（加10像素间隙）
        x += width + 10
        p += 1
    # 重置X坐标，更新Y坐标（加10像素间隙）
    x = 0
    y += height + 10

# 5. 显示并保存
im_out.show()
im_out.save('output_rgb.jpg')  # 保存为RGB模式
im_out.convert("CMYK").save('output_cmyk.jpg')  # 转换为CMYK模式保存

4. 案例总结及思考

（1）案例总结
  • 图像模式：不同模式适用于不同场景——RGB用于屏幕显示，CMYK用于印刷，灰度模式用于黑白处理，Lab用于高质量色彩管理。选择模式需结合最终用途。

当前程序存在的问题：

  • 代码结构松散：分割和拼合逻辑无函数封装，可读性、可维护性差。

  • 参数化配置：支持自定义行列数、间隙大小，适应更多场景。

1. 相关知识

（1）图像混合模式

图像混合模式通过数学运算融合两张图像的像素值，产生不同视觉效果。Pillow的ImageChops模块提供多种混合函数，常用模式如下：

正片叠底（multiply）

减色运算，混合后图像变暗。公式：out = (img1 * img2) / 255，适用于叠加阴影、增强对比度。

滤色（screen）

加色运算，混合后图像变亮。公式：out = 255 - ((255-img1)*(255-img2))/255，适用于叠加高光、提亮画面。

变暗/变亮（darker/lighter）

变暗：取两张图像对应像素最小值；变亮：取最大值。适用于简单的亮度调整。

相加/相减（add/subtract）

相加：out = (img1+img2)/scale + offset；相减：out = (img1-img2)/scale + offset，适用于亮度叠加或差值计算。

反相（invert）

像素值取反（255-原像素），产生负片效果，适用于艺术化处理。

叠加/柔光（overlay/soft_light）

叠加结合正片叠底和滤色，产生光泽效果；柔光根据原图亮度调整混合效果，适用于质感增强。

（2） ImageChops模块的“混合模式”

Pillow库的ImageChops模块中包含了多种图像混合模式，可以创建多种图像叠加效果。

例4-5：多种混合模式实现 

# 图像混合模式函数
from PIL import Image, ImageChops

# 定义混合函数
def blend_images(image1, image2, mode):
    if mode == 'normal':     # 平均混合
        return ImageChops.blend(image1, image2, 0.5)
    elif mode == 'multiple': # 正片叠底
        return ImageChops.multiply(image1, image2)
    elif mode == 'screen':   # 滤色
        return ImageChops.screen(image1, image2)
    elif mode == 'invert':   # 反相（仅处理image1）
        return ImageChops.invert(image1)
    else:
        raise ValueError("Unsupported blend mode")

# 加载并调整图像大小（确保尺寸一致）
image1 = Image.open('images/天坛.jpg')
image2 = Image.open('images/天空.jpg')
if image1.size != image2.size:
    image2 = image2.resize(image1.size)

# 测试不同混合模式并保存
modes = ['normal', 'multiple', 'screen', 'invert']
for mode in modes:
    blended_img = blend_images(image1, image2, mode)
    blended_img.save(f'blended_image_{mode}.png')

本案例通过Pillow库实现图像混合和遮罩合成，核心为混合函数、遮罩合成函数及主程序交互逻辑。 

# 1. 导入库
from PIL import Image, ImageChops

# 2. 定义图像混合函数
def blend_images(image1, image2, mode):
    """根据混合模式混合两张图像"""
    if mode == 'multiply':  # 正片叠底
        return ImageChops.multiply(image1, image2)
    elif mode == 'screen':  # 滤色
        return ImageChops.screen(image1, image2)
    elif mode == 'darker':  # 变暗
        return ImageChops.darker(image1, image2)
    elif mode == 'lighter':  # 变亮
        return ImageChops.lighter(image1, image2)
    elif mode == 'overlay':  # 叠加
        return ImageChops.overlay(image1, image2)
    elif mode == 'soft_light':  # 柔光
        return ImageChops.soft_light(image1, image2)
    else:
        raise ValueError("Unsupported blend mode")

# 3. 定义遮罩合成函数
def composite_images(image1, image2, mask):
    """使用遮罩合成两张图像"""
    return ImageChops.composite(image1, image2, mask)

# 4. 主程序
def main():
    # 输入参数
    img1_path = input("请输入要合成的第一张图像路径（如 images/夜色.jpg）：")
    img2_path = input("请输入要合成的第二张图像路径（如 images/烟花.jpg）：")
    background_path = input("请输入背景图像路径（如 images/草地.jpg）：")
    mask_path = input("请输入遮罩图像路径（如 images/小鹿.png）：")
    blend_mode = input("请输入混合模式（如 screen、multiply 等）：")

    # 打开图像（异常处理）
    try:
        img1 = Image.open(img1_path)
        img2 = Image.open(img2_path)
        background = Image.open(background_path)
        mask = Image.open(mask_path)
    except FileNotFoundError:
        print("文件路径错误，请检查文件是否存在。")
        return

    # 调整尺寸一致
    img2 = img2.resize(img1.size)
    background = background.resize(img1.size)
    mask = mask.resize(img1.size)

    # 图像混合（异常处理）
    try:
        blended_img = blend_images(img1, img2, blend_mode)
        blended_img.save(f"blended_image_{blend_mode}.jpg")
        blended_img.show()
    except ValueError as e:
        print(f"混合模式错误：{e}")
        return

    # 遮罩合成
    composite_img = composite_images(blended_img, background, mask)
    composite_img.save("composite_image.jpg")
    composite_img.show()

    # 验证像素值
    print(f"原始图像1（{img1_path}）在(100, 100)处的像素值：{img1.getpixel((100, 100))}")
    print(f"原始图像2（{img2_path}）在(100, 100)处的像素值：{img2.getpixel((100, 100))}")
    print(f"混合图像（{blend_mode}模式）在(100, 100)处的像素值：{blended_img.getpixel((100, 100))}")
    print(f"遮罩合成图像在(100, 100)处的像素值：{composite_img.getpixel((100, 100))}")

# 运行主程序
if __name__ == "__main__":
    main()

（1）图像增强（ImageEnhance模块）

ImageEnhance模块提供亮度、对比度、锐度、颜色的调整功能，通过enhance(factor)实现，factor=1为原图，<1减弱，>1增强。常用方法如表4-4所示。

表4-4 ImageEnhance模块常用方法

方法 描述
Brightness(factor) 调整亮度，factor>1变亮，<1变暗
Contrast(factor) 调整对比度，factor>1更鲜明，<1更柔和
Sharpness(factor) 调整锐度，factor>1更清晰，<1更模糊
Color(factor) 调整颜色饱和度，factor>1增强，<1减淡

# 1. 导入库
from PIL import Image, ImageEnhance, ImageDraw, ImageFilter, ImageFont
import os, logging

# 2. 定义批处理函数
def batch_process_images(input_folder, output_folder):
    # 检查目标文件夹，不存在则创建
    if not os.path.exists(output_folder):
        os.makedirs(output_folder)
        logging.info(f"Created output folder: {output_folder}")

    # 遍历输入文件夹
    for filename in os.listdir(input_folder):
        # 筛选图像文件（png/jpg/gif）
        if filename.lower().endswith(('.png', '.jpg', '.gif')):
            input_path = os.path.join(input_folder, filename)
            output_path = os.path.join(output_folder, filename)

            try:
                # 打开图像
                with Image.open(input_path) as img:
                    # 3. 图像增强：对比度增强（2倍）
                    enhancer = ImageEnhance.Contrast(img)
                    enhanced_img = enhancer.enhance(2.0)

                    # 4. 应用滤镜：锐化
                    enhanced_img = enhanced_img.filter(ImageFilter.SHARPEN)

                    # 5. 添加文字（文件名）
                    draw = ImageDraw.Draw(enhanced_img)
                    # 加载字体
                    font = ImageFont.truetype('C:/Windows/Fonts/msyh.ttc', size=50)
                    # 获取文件名（去掉扩展名）
                    file_name = os.path.splitext(filename)[0]
                    draw.text((50, 80), text=file_name, fill='#ff0', font=font)

                    # 6. 保存图像
                    enhanced_img.save(output_path)

                # 记录日志
                logging.basicConfig(filename='batch_process.log', level=logging.INFO)
                logging.info(f"Processed {filename}")

            except Exception as e:
                # 异常处理
                print(f"Error processing {filename}: {e}")

# 3. 调用批处理函数
if __name__ == "__main__":
    input_folder = 'source_image'   # 源图像文件夹
    output_folder = 'dest_image'    # 目标文件夹
    batch_process_images(input_folder, output_folder)

# 例4-14：批处理类
from PIL import Image, ImageEnhance, ImageDraw, ImageFilter, ImageFont
import os
import logging

# 配置日志（支持中文）
logging.basicConfig(
    filename='batch_process.log',
    level=logging.INFO,
    encoding='utf-8',
    format='%(asctime)s - %(levelname)s - %(message)s'
)

class ImageBatchProcessor:
    def __init__(self, input_folder, output_folder):
        self.input_folder = input_folder
        self.output_folder = output_folder

    def check_output_folder(self):
        """检查输出文件夹，不存在则创建"""
        if not os.path.exists(self.output_folder):
            os.makedirs(self.output_folder)
            logging.info(f"创建输出文件夹: {self.output_folder}")

    def process_image(self, input_path, output_path):
        """处理单张图像"""
        try:
            with Image.open(input_path) as img:
                # 对比度增强（2倍）
                enhancer = ImageEnhance.Contrast(img)
                enhanced_img = enhancer.enhance(2.0)

                # 锐化滤镜
                enhanced_img = enhanced_img.filter(ImageFilter.SHARPEN)

                # 添加文字水印
                draw = ImageDraw.Draw(enhanced_img)
                font = ImageFont.truetype('C:/Windows/Fonts/msyh.ttc', size=50)
                file_name = os.path.splitext(os.path.basename(input_path))[0]
                draw.text((50, 80), text=file_name, fill='#ff0', font=font)

                # 保存
                enhanced_img.save(output_path)
                logging.info(f"处理文件: {os.path.basename(input_path)}")
        except Exception as e:
            logging.error(f"处理文件失败: {os.path.basename(input_path)} - {e}")
            print(f"处理文件失败: {os.path.basename(input_path)} - {e}")

    def batch_process_images(self):
        """批量处理图像"""
        self.check_output_folder()
        for filename in os.listdir(self.input_folder):
            if filename.lower().endswith(('.png', '.jpg', '.gif')):
                input_path = os.path.join(self.input_folder, filename)
                output_path = os.path.join(self.output_folder, filename)
                self.process_image(input_path, output_path)

# 运行程序
if __name__ == "__main__":
    processor = ImageBatchProcessor('source_image', 'dest_image')
    processor.batch_process_images()

  • 支持设置文字内容、位置（X/Y坐标）、大小、颜色（集成颜色选择器）、样式（普通/阴影/轮廓）（如图4-39）。
  • 颜色选择：使用tkinter.colorchooser.askcolor获取颜色值。
  • 核心代码：ImageDraw.Draw.text()，阴影效果通过偏移绘制实现。

6. 核心技术要点
  • 图像显示：将Pillow图像转换为Tkinter的PhotoImage，显示在Label上。
  • 撤回功能：用列表history = []保存每次处理前的图像对象，撤回时history.pop()恢复。
  • 实时预览：每次操作后立即更新显示区域的图像，无需手动刷新。

系统扩展建议：可新增滤镜效果（如高斯模糊、油画效果）、文字样式（如旋转文字、渐变文字）、批量处理功能（导入文件夹批量操作），进一步提升工具实用性。
