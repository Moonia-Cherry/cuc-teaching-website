3.4 相关知识

1. GUI简介

（1）什么是GUI？

日常使用计算机时，启动应用程序后屏幕会呈现图形化窗口（如QQ登录窗口、记事本窗口等），窗口中包含文本框、按钮、菜单等交互元素，这些元素统称为GUI（图形用户界面，Graphical User Interface）。

GUI开发的核心：在窗口中合理组织组件（标签、按钮等），通过组件调用程序功能。设计良好的GUI可降低用户操作门槛，提升使用体验。

（2）Python中的GUI库

Python常用GUI库对比如下：

Tkinter：Python标准库，内置GUI库，无需额外安装，适合小型项目。

PyQt：跨平台GUI库，功能强大，需安装（pip install PyQt5），支持Qt Designer可视化设计。

Kivy：跨平台GUI库，基于Python，需安装（pip install kivy），支持多点触控。

PySide2：Qt公司的Python绑定库，需安装（pip install PySide2），提供与Qt Designer的集成。

3. 图形化界面编程的基本流程

使用tkinter创建GUI的5个步骤：

  1. 导入tkinter模块（如import tkinter as tk）
  2. 创建主窗口（根窗口）：root_window = tk.Tk()
  3. 添加交互控件，并编写事件函数
  4. 窗口布局：设置控件在窗口中的位置
  5. 启动主循环：root_window.mainloop()（窗口持续显示，直到关闭）

4. 事件处理

事件（event）：界面中发生的操作（如鼠标单击、键盘按键），tkinter常见事件类型如表3-1所示。

表3-1 tkinter中的常见事件

事件 描述
<B1-Motion> 按住鼠标左键移动（B2=中键，B3=右键）
<Button-i> 按下鼠标左键（i=1/2/3，对应左/中/右键）
<ButtonRelease-i> 释放鼠标左键（i=1/2/3，对应左/中/右键）

<Leave> 鼠标离开组件区域
<Key> 按下键盘任意键
<Return> 按下“Enter”回车键
<BackSpace> 按下“BackSpace”退格键

事件处理：事件发生时程序的响应操作（如单击“计算”按钮触发热量计算）。绑定方式有两种：

  1. 创建组件时，通过command属性绑定函数（适用于简单单击事件）。
  2. 通过bind方法绑定事件（支持更多事件类型），语法： 
    widget.bind(event, func)
# widget：组件对象；event：事件类型（如表3-1）；func：事件处理函数

5. 布局管理

布局管理用于设置组件在窗口中的位置，tkinter提供三种布局方式，组件需布局后才能显示：

  • pack布局：

    相对布局，按添加顺序线性排列，支持垂直/水平方向，适合简单界面。

    常用参数：side（方向）、fill（填充方式）、expand（是否扩展）

  • grid布局：

    网格布局，将窗口划分为行列表格，组件放入单元格，适合复杂界面。

    常用参数：row（行）、column（列）、columnspan（跨列）、rowspan（跨行）

  • place布局：

    精确布局，通过X/Y坐标指定组件位置，适合需固定位置的场景。

    常用参数：x（X轴坐标）、y（Y轴坐标）、width（宽度）、height（高度）

BMI计算器案例

BMI（Body Mass Index）即身体质量指数，是评估人体肥胖程度和健康状况的常用指标。计算公式为：BMI = 体重(kg) / 身高(m)²。

核心实现思路
  • 创建主窗口和必要的标签、输入框、按钮等组件
  • 编写计算BMI的函数，并根据计算结果给出健康建议
  • 设置组件的布局，使其美观易用
参考代码
import tkinter as tk
from tkinter import messagebox

# 创建主窗口
root = tk.Tk()
root.title("BMI计算器")
root.geometry("400x300")

# 函数：计算BMI并显示结果
def calculate_bmi():
    try:
        # 获取用户输入的身高和体重
        weight = float(weight_entry.get())
        height = float(height_entry.get()) / 100  # 转换为米

        # 计算BMI
        bmi = weight / (height ** 2)

        # 判断BMI范围并给出建议
        if bmi < 18.5:
            advice = "偏瘦，建议增加营养摄入。"
        elif 18.5 <= bmi < 24:
            advice = "正常，继续保持健康生活方式。"
        elif 24 <= bmi < 28:
            advice = "偏胖，建议控制饮食并加强运动。"
        else:
            advice = "肥胖，建议咨询医生并制定减肥计划。"

        # 显示结果
        result_label.config(text=f"您的BMI指数为：{bmi:.2f}\n{advice}")
    except:
        messagebox.showerror("输入错误", "请输入有效的身高和体重数值！")

# 创建标签和输入框
weight_label = tk.Label(root, text="体重（kg）：", font=("微软雅黑", 12))
weight_label.pack(pady=10)
weight_entry = tk.Entry(root, font=("微软雅黑", 12), width=20)
weight_entry.pack(pady=5)

height_label = tk.Label(root, text="身高（cm）：", font=("微软雅黑", 12))
height_label.pack(pady=10)
height_entry = tk.Entry(root, font=("微软雅黑", 12), width=20)
height_entry.pack(pady=5)

# 创建计算按钮
calculate_button = tk.Button(root, text="计算BMI", font=("微软雅黑", 12), command=calculate_bmi)
calculate_button.pack(pady=20)

# 创建结果标签
result_label = tk.Label(root, text="", font=("微软雅黑", 12), justify="left")
result_label.pack(pady=10)

# 启动主循环
root.mainloop()

银行利息计算器案例

本案例实现一个简单的银行利息计算器，根据用户输入的本金、年利率和存款期限，计算到期后的本息和。

核心实现思路
  • 创建主窗口和必要的组件
  • 编写计算利息的函数
  • 设置合理的布局
参考代码
import tkinter as tk
from tkinter import ttk, messagebox

# 创建主窗口
root = tk.Tk()
root.title("银行利息计算器")
root.geometry("450x350")

# 函数：计算利息

def calculate_interest():
    try:
        # 获取用户输入
        principal = float(principal_entry.get())
        rate = float(rate_entry.get())
        years = float(years_entry.get())

        # 计算利息和本息和
        interest = principal * rate * years / 100
        total = principal + interest

        # 显示结果
        result_var.set(f"利息：{interest:.2f}元\n本息和：{total:.2f}元")
    except:
        messagebox.showerror("输入错误", "请输入有效的数值！")

# 创建标签和输入框

# 本金
principal_frame = ttk.Frame(root)
principal_frame.pack(fill="x", padx=20, pady=10)

principal_label = ttk.Label(principal_frame, text="本金（元）：", font=("微软雅黑", 12))
principal_label.pack(side="left", padx=5)

principal_entry = ttk.Entry(principal_frame, font=("微软雅黑", 12), width=20)
principal_entry.pack(side="left", padx=5)

# 年利率
rate_frame = ttk.Frame(root)
rate_frame.pack(fill="x", padx=20, pady=10)

rate_label = ttk.Label(rate_frame, text="年利率（%）：", font=("微软雅黑", 12))
rate_label.pack(side="left", padx=5)

rate_entry = ttk.Entry(rate_frame, font=("微软雅黑", 12), width=20)
rate_entry.pack(side="left", padx=5)

# 存款期限
years_frame = ttk.Frame(root)
years_frame.pack(fill="x", padx=20, pady=10)

years_label = ttk.Label(years_frame, text="存款期限（年）：", font=("微软雅黑", 12))
years_label.pack(side="left", padx=5)

years_entry = ttk.Entry(years_frame, font=("微软雅黑", 12), width=20)
years_entry.pack(side="left", padx=5)

# 创建计算按钮
calculate_button = ttk.Button(root, text="计算利息", command=calculate_interest)
calculate_button.pack(pady=20)

# 创建结果显示区域
result_var = tk.StringVar()
result_label = ttk.Label(root, textvariable=result_var, font=("微软雅黑", 12), justify="left")
result_label.pack(pady=10)

# 启动主循环
root.mainloop()
