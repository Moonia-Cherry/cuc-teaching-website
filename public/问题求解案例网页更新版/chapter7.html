7.5 相关知识

1. 广告投放效果衡量指标

衡量广告投放效果的核心指标有流量指标、成本指标、收益指标、用户行为指标等，如图7-1所示。

图7-1 常用广告效果衡量指标

结合本案例的数据集，下面重点讨论流量指标、成本指标和收益指标。

（1）流量指标
  • 展示量：指广告在一定时间内被展示的次数。展示量越高，意味着有更多机会被潜在客户看到。
  • 点击量：用户点击广告的次数，体现广告吸引用户进一步了解的能力。
  • 点击率（Click-Through Rate, CTR）：指广告被点击的次数与广告展示量的比例，用于评估广告吸引力和用户兴趣度，公式如下：
    \[ CTR = \frac{点击次数}{广告展示次数} \]
  • 转化率（CVR，Conversion Rate）：指用户完成特定转化行为的次数与点击广告总次数之比，高转化率表明广告能有效引导用户，公式如下：
    \[咨询转化率 = \frac{咨询量}{点击量}\]

    \[购买转化率 = \frac{购买量}{点击量}\]
（2）成本指标
  • 每次点击成本（CPC，Cost Per Click）：广告主为用户每一次有效点击支付的费用，反映流量获取成本效率，公式如下：
    \[ CPC = \frac{广告费用}{点击量} \]

    示例：广告花费200元，获得500次点击，则 \( CPC = \frac{200}{500} = 0.4 \) 元/次。

  • 每次行动成本（CPA，Cost Per Action）：广告主为用户每一次特定转化行为支付的平均费用（如购买、注册），公式如下：
    \[ CPA = \frac{广告费用}{转化量} \]
  • 每千次展示成本（CPM，Cost Per Mille）：广告主为每千次广告展示支付的费用，适用于品牌展示类广告，公式如下：
    \[ CPM = \frac{广告费用}{展示量} \times 1000 \]
（3）投资回报指标

投资回报指标衡量广告投入与收益的关系，帮助判断广告支出合理性，核心指标如下：

  • 投资回报率（ROI，Return on Investment）：衡量整体投资净回报率，扣除所有成本（广告+产品+运营等），公式如下：
    \[ ROI = \frac{广告收入 - 广告成本}{广告费用} \]
  • 广告支出回报率（ROAS，Return on Advertising Spend）：衡量广告支出的直接回报率，仅关注广告投入与收入，公式如下：
    \[ ROAS = \frac{广告收入}{广告费用} \]

2. 数据分析基本流程

数据分析的基本流程分为5个步骤，具体如下：

  1. 明确目的：确定数据分析的核心问题和目标（如“哪组广告投放效果最好？”）。
  2. 获取数据：通过客户提供、问卷调查、公开数据源下载或爬虫技术收集待分析数据。
  3. 数据处理：包括数据清洗（处理缺失值、重复值、异常值）、数据转换（标准化、归一化）、特征选择等。
  4. 数据分析：根据问题进行统计分析（求和、均值、分类汇总）或建模分析（相关性、回归等）。
  5. 结果展现：通过可视化（图表）呈现分析结果，并解读结论以支持决策。

3. 相关性分析

相关性分析用于研究两个或多个变量之间的关联程度，核心作用包括：

  • 探索数据关系：发现变量间内在联系（如广告展示量与点击量的关系），为进一步研究提供线索。
  • 变量筛选和降维：去除高度相关的冗余变量，避免多重共线性对分析结果的影响。
  • 预测和决策支持：基于变量相关性制定策略（如根据广告投入与销售额的正相关调整预算）。

Pandas中用DataFrame.corr()计算各列间相关性，返回相关系数矩阵，语法如下： 

DataFrame.corr(method='pearson', min_periods=1)

关键参数说明：

  • method：相关性计算方法，默认'pearson'（皮尔逊系数，衡量线性关系），可选'kendall'（肯德尔秩相关）、'spearman'（斯皮尔曼秩相关，适用于非线性关系）。
  • min_periods：每对列需满足的最小观测值数量，默认1。

4. 分类汇总

分类汇总是对同类数据进行统计汇总（求和、均值等），Pandas中用groupby()方法实现，核心是明确"分类字段、汇总字段、汇总方式"。

groupby()方法语法：

df.groupby(by, axis, level, as_index, sort, ……)

常用参数说明如表7-1所示：

表7-1 groupby()参数说明

参数 含义
by 分组依据，可为列名、列名列表或返回分组值的函数
axis 分组轴向：axis=0（行方向，默认），axis=1（列方向）
level 用于分组的索引级别（默认无）
as_index 是否将分组键作为行索引：True（默认），False（分组键为普通列）
sort 分组内数据是否按索引排序：True（默认），False（保留原始顺序）

分类汇总常用的有两种方式：

  1. 方式1：直接对列运用汇总函数 
    df.groupby(分类列)[汇总列].汇总函数()
  2. 方式2：用agg()函数多字段汇总 
    df.groupby(分类列).agg({"列1":"汇总函数", "列2":"汇总函数", ……})

常用汇总函数如表7-2所示：

7.7 案例总结与建议

核心结论 具体建议
男性受众ROAS均高于女性 1. 将男性作为主要投放对象；
2. 优化广告素材（如突出“男性偏好口味”）提升男性点击率和转化率。
广告916转化效果最优（点击率、转化率、ROAS均最高），广告1178效果最差 1. 预算有限时，加大广告916投放，减少广告1178投放；
2. 分析广告916的高转化原因（如素材、定向），复用到其他广告。
广告1178定位不准确（受众匹配度低） 1. 缩小广告1178定向范围（如排除35岁以上人群、兴趣ID 18/26/62）；
2. 优化广告1178内容，突出用户需求（如“年轻群体专属优惠”）。
咨询量与购买量强相关（r=0.86） 1. 建立“5分钟咨询响应机制”；
2. 培训客服话术，提升“咨询→购买”转化效率。
